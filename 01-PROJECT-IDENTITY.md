# Project Identity and Product Intent

## Name

**Tech Katta**

## Owner / author

Yash Bhoomkar.

## Primary URL

`https://tech.katta.cc`

## Positioning

Tech Katta is a personal engineering knowledge base.

The important positioning decision is:

> This is a real engineer's personal technical notebook that happens to be very well designed.

It is **not** intended to resemble:
- a generic documentation portal
- an AI-generated course platform
- a corporate documentation template
- a clone of another learning site

## Content philosophy

The project intentionally follows:

1. Start from a primitive or mental model.
2. Explain how the pieces work.
3. Show where the technology fits in a real system.
4. Discuss trade-offs and operational consequences.
5. Use diagrams, numbers and code when they clarify the idea.
6. Write what was actually learned rather than producing generic summaries.

The user specifically wanted the interface language humanized because the earlier version felt too AI-generated.

Examples of the current editorial language:
- "notes on building systems"
- "Engineering notes"
- "things I’m learning, building, and trying to understand"
- "Things I learn, build, and eventually understand."
- "What I’m studying"
- "Notes in this topic"
- "A few things to think about"
- "Before you move on"
- "In short"
- "Progress"
- "In this note"

## Audience journey

The intended journey is:

LinkedIn post
→ article click
→ Tech Katta
→ first 5–10 seconds
→ read article
→ inspect diagrams
→ navigate to another note
→ decide whether to bookmark/share/follow/return

A useful independent reviewer should therefore evaluate the product as a software engineer discovering it through a LinkedIn post, not merely as a visual-design exercise.

## Current design language

The site is dark-only.

Core visual direction:
- dark navy/near-black background
- purple/lavender accent
- restrained borders
- technical/editorial typography
- minimal rounded surfaces
- static explanatory diagrams
- no excessive card shadows
- no excessive pill-shaped UI
- no artificial "AI course" feel

The accent has historically centered around `#b99af7`; the main dark background is around `#05071c`.

## Brand

The UI uses:
- TK mark
- Tech Katta wordmark
- "notes on building systems" descriptor

The sidebar has:

## Important product constraint

Do not "improve" the design by making it more generic, more rounded, more dashboard-like, or more obviously AI-generated.

When changing copy or UI, preserve the editorial engineering-notebook identity.
